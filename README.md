# zomato-analytics-dashboar--

## Project Overview
This project analyzes Zomato restaurant data to understand restaurant ratings, pricing, and restaurant trends.

## Tools Used
- SQL
- Microsoft Excel
- Power BI
- Tableau

## Project Objectives
- Analyze restaurant ratings and customer preferences.
- Understand restaurant pricing and trends.
- Create dashboards to visualize insights.
- Practice data analysis and visualization skills.

## Key Learnings
Improved my skills in data cleaning, SQL queries, data analysis, and dashboard development.
